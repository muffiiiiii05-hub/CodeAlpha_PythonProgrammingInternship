# CodeAlpha_PythonProgrammingInternship

This repository contains the projects completed during my Python Programming Internship at CodeAlpha.

## Projects Completed

### Task 1 - Hangman Game

A simple console-based word guessing game developed using Python. The user has to guess the hidden word within a limited number of incorrect guesses.

### Task 2 - Stock Portfolio Tracker

A Python program that calculates the total investment based on stock prices and the quantity of stocks entered by the user.

### Task 3 - Basic Chatbot

A simple Python-based chatbot that interacts with the user and provides responses to predefined questions or messages.
